# ClassVision Archive

This directory stores legacy prototypes, prior experimental client/server implementations, and experimental stacks that are not active in the production ClassVision 2.0 runtime (`backend/`, `frontend/`, `mobile/`).

## Contents:
- **`archive/legacy/`**: Original single-tier Python prototype scripts and reference client.
- **`archive/future/`**: Early exploratory design mockups and alternative web/server templates.
